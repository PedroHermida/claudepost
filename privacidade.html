Política de Privacidade

Última atualização: 12 de novembro de 2026

Esta política explica como o claudepost ("a ferramenta") trata os dados. O claudepost é uma ferramenta pessoal que roda no computador do próprio usuário para publicar os vídeos dele nas contas dele.

1. Uso dos Serviços de API do YouTube

O claudepost usa os Serviços de API do YouTube. Ao conectar uma conta do YouTube, você também concorda com os Termos de Serviço do YouTube, e os dados tratados pelo Google seguem a Política de Privacidade do Google.

2. Quais dados são acessados

  • Permissão para enviar vídeos (youtube.upload): usada apenas para enviar ao seu canal os vídeos que você mesmo escolheu publicar.
  • Leitura da sua conta do YouTube (youtube.readonly): usada apenas para identificar o seu canal (nome e ID) e acompanhar o processamento dos vídeos enviados.
  • Tokens de acesso fornecidos pelo Google após a sua autorização.

A ferramenta não acessa a sua senha, os seus inscritos, mensagens, comentários, histórico ou qualquer outro dado.

3. Onde os dados ficam e como são protegidos

  • Tudo fica somente no seu computador. Não existe servidor, nuvem ou banco de dados externo do claudepost.
  • Os tokens são guardados criptografados (AES-256), com a chave protegida pelo Gerenciador de Credenciais do Windows.
  • Os vídeos permanecem no seu computador e são enviados diretamente ao YouTube.

4. Compartilhamento

O claudepost não vende, não compartilha e não transfere dados a terceiros. Os dados só são enviados ao próprio Google/YouTube, quando você pede para publicar.

5. Retenção e exclusão

  • Ao clicar em Desconectar na ferramenta, os tokens são apagados do computador e o acesso é revogado no Google.
  • Você também pode retirar o acesso a qualquer momento em security.google.com/settings/security/permissions.
  • Apagar a pasta de dados da ferramenta remove todas as informações guardadas por ela.

6. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

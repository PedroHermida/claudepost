claudepost

O claudepost é uma ferramenta pessoal, executada no computador do próprio criador, para agendar e publicar os seus próprios vídeos nas suas contas de redes sociais (como o YouTube), a partir de uma única tela.

Como funciona

  • O vídeo fica no computador do usuário e é enviado diretamente à rede social escolhida, usando as APIs oficiais.
  • A conexão com cada rede é feita pelo login oficial dela (OAuth). A ferramenta nunca pede nem guarda senhas.
  • As autorizações ficam criptografadas no próprio computador do usuário. Não há servidor nem banco de dados na nuvem.
  • No YouTube, a ferramenta usa os Serviços de API do YouTube apenas para enviar vídeos ao canal do próprio usuário e acompanhar o processamento deles.

Quem usa

É de uso pessoal do próprio criador do conteúdo. Não é um serviço oferecido ao público e não há cadastro de usuários.
